# 1. Dynamic UI & Posture Corruption
Since the player character gets colder, darker, and more ruthless as the soul count rises, let the game's interface physically rot alongside them:
- Early Game (Ch 1–4): Warm, classic RPG menus, soft sounds, upright character idle animation.
- Mid Game (Ch 5–12): Menus get darker violet, ambient music starts picking up low reverse-reverb, and your idle animation becomes slouched and restless.
- Late Game / Post-Judgement (Ch 14+): Text occasionally glitches into Skotos runes, execution prompts replace standard attack names, and companions like Scepter or Puppy react nervously if you leave the menu open too long.
# 2. Deepen the "Skotos" Twist with Glitch Lore
The lore reveal that the Tome is lying about the "Dark Set" (and is actually tricking you into reviving the dark entity Skotos) is a great narrative twist. To make it land harder:
Whenever you insert a PageStone, show a 1-second subliminal flash of Skotos's true eye or a corrupted memory frame.
